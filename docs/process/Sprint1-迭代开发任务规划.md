## 一、Sprint 1 目标

> 交付一个能"**自主制订阶段计划 + 强制追踪 12h 学习习惯 + 深度监控英语短板 + 记录执行阻碍与心得**"的闭环控制面板，防止"假期假复习、假自律"。

**核心闭环**：制定阶段计划 → 分配每日时间 → 计时追踪执行 → 填写执行备注 → 对齐 12h 规范

## 三、Sprint 1 任务清单

### 任务分组 A：学科任务模板库（Day 1-2，后端 + 数据）

**业务背景**：家长会明确了 7 科的具体作业，日程表 xlsx 精确到每周每科的任务明细。

#### A-1. 新增数据库表 `subject_templates`

```sql
CREATE TABLE subject_templates (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  subject TEXT NOT NULL,          -- 语文/数学/英语/物理/化学/生物/体育
  task_name TEXT NOT NULL,        -- 任务名称（如"海淀期末卷限时训练"）
  task_detail TEXT,               -- 详细要求（如"限时2小时，黑笔作答红蓝笔订正"）
  frequency TEXT,                 -- 频次：每日/隔日/周N次/自定义
  estimated_minutes INTEGER,      -- 预计耗时（分钟）
  week_number INTEGER,            -- 适用周次 1-4，NULL=全周期
  sort_order INTEGER DEFAULT 0
);
```

- **工作量**：1 个 SQL 迁移 + db.js 无变动（自动建表）
- **验收**：表创建成功，可通过 `sqlite3` 直接查询

#### A-2. 编写 7 科模板 seed 数据（从日程表 xlsx 提取）

按学科分别提取，精确到页码和题号。示例（数学）：

```js
// db/seed_templates.js
const MATH_TEMPLATES = [
  { subject: '数学', task_name: '海淀期末卷限时训练', task_detail: '限时2小时完成，黑笔作答、红蓝笔订正', frequency: '周1次', estimated_minutes: 120, week_number: 1 },
  { subject: '数学', task_name: '西城期末卷限时训练', task_detail: '限时2小时完成', frequency: '周1次', estimated_minutes: 120, week_number: 1 },
  { subject: '数学', task_name: '统练1-2错题重做', task_detail: '错题反思：梳理解题思路，标注知识点', frequency: '周1次', estimated_minutes: 60, week_number: 1 },
  // ... 4周 × 7科
];
```

- **数据来源**：`docs/design/曾子轩高三暑假学习日程表 .xlsx`
- **工作量**：7 科 × 约 4-6 条任务/科 = 约 35 条
- **验收**：`node db/seed_templates.js` 后，`SELECT * FROM subject_templates` 返回正确条数

#### A-3. 新增模板 API（2 个端点）

| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/api/templates?subject=数学` | 按学科筛选模板列表 |
| POST | `/api/templates/import` | 批量导入指定模板到当前主题（自动创建 TASK 节点） |

- **Controller**：`controllers/templateController.js`
- **Route**：`routes/templates.js`
- **POST /api/templates/import 请求体**：
```json
{
  "themeId": 1,
  "templateIds": [1, 2, 3, 5, 8]
}
```
- **工作量**：~80 行
- **验收**：curl 调用后，`planning_nodes` 中出现对应的 TASK 类型节点

#### A-4. PlansPage 新增「导入学科模板」按钮

在选择主题后，主题操作区增加一个「导入模板」按钮：
- 点击弹出模态框
- 按学科 Tab 切换（语文/数学/英语/物理/化学/生物/体育）
- 每科显示模板任务列表（checkbox 多选）
- 确认后调用 `POST /api/templates/import`
- 导入完成刷新重点项列表

- **工作量**：~120 行 JSX
- **验收**：TC-01 — 一键导入数学《天利38套》及英语标准集，首页任务清单对应刷新

### 任务分组 C：任务打卡与防自欺验证（Day 3-4，前端为主）

#### C-1. 打卡弹窗组件 `TaskCheckinModal`

在 PlansPage 的任务卡片上增加「去打卡」按钮，点击弹出打卡弹窗：

```
┌──────────────────────────────────────────┐
│  任务打卡：数学 — 海淀期末卷限时训练      │
│  预计耗时：120 分钟                        │
├──────────────────────────────────────────┤
│  1. 实际耗时：[___] 分钟                   │
│                                           │
│  2. 规范验证：                             │
│     [ ] 我已用黑笔作答，红/蓝笔完成订正     │
│     [📷 上传练习照片]（可选）               │
│                                           │
│  3. 执行阻碍（可多选）：                   │
│     [ ] 题目偏难，大幅超出用时              │
│     [ ] 基础概念模糊，需再读教材            │
│     [ ] 专注度下滑，受手机干扰              │
│     [ ] 顺利掌握，完成质量高                │
│     [ ] 审题不清/读题遗漏                  │
│     [ ] 计算失误                           │
│                                           │
│  4. 补充说明：                             │
│     [_____________________________]       │
│                                           │
│  完成度：[━━━━━━━━━━░] 80%                 │
│                                           │
│  [ 标记为未完成 ]    [ 确认打卡 ]          │
└──────────────────────────────────────────┘
```

- **防自欺逻辑**：若任务 `task_detail` 包含"黑笔作答红蓝笔订正"，则规范验证复选框为必选，未勾选时「确认打卡」按钮 disabled
- **验收**：TC-04 — 不勾选声明时按钮不可用，拦截提示
- **工作量**：~180 行 JSX

#### C-2. 打卡数据提交

- 「确认打卡」调用 `POST /api/daily-executions`
- 阻碍标签存为 `notes` 字段的 JSON：
  ```json
  {
    "tags": ["题目偏难", "基础概念模糊"],
    "customNote": "解析几何辅助线还是不太会",
    "actualMinutes": 135,
    "verifiedDeclaration": true
  }
  ```
- 完成度根据「实际耗时 vs 预计耗时」和打卡情况进行判定
- **工作量**：~40 行逻辑
- **验收**：TC-05 — 标签和备注永久留存，可在执行记录中翻查
