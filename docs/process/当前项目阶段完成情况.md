## 四、技术债务与已知问题

### 待修复

| 问题 | 严重程度 | 说明 |
|------|----------|------|
| `stop.sh` 仅支持 Windows | 低 | 使用 `taskkill` 命令，Linux 不可用 |
| `test-api.ps1` 仅支持 PowerShell | 低 | 无 Linux/macOS 替代脚本 |
| PlansPage 一次加载全部主题 | 中 | 无明显翻页控件，v1 数据量小暂不影响 |
| 前端无全局 Loading/Error 组件 | 中 | 各页面自行处理，代码重复 |

### 架构限制

| 限制 | 影响 | 缓解方案 |
|------|------|----------|
| SQLite 单文件 | 并发写入瓶颈 | 当前单人使用无影响，后续可迁移 PostgreSQL |
| 无路由库 | 刷新回到首页 | 后续可用 hash 路由解决 |
| 无用户系统 | 所有数据共享 | 后续可加入多用户/家庭成员 |
