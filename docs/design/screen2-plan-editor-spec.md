## 三、功能模块详解

### 3.1 阶段元信息编辑

| 字段 | 类型 | 说明 |
|------|------|------|
| 阶段名称 | text input | 直观描述 |
| 时间范围 | date × 2 | 开始日期 至 结束日期 |
| 核心突破学科 | select | 从 SUBJECTS 列表选择，标记本阶段重点 |

### 3.2 预设模板导入

| 模板名称 | 包含任务 |
|----------|----------|
| 英语突破预设 | 词汇背诵(45min/日) + 听口套题(30min/周3) + 完型阅读(40min/隔日) |
| 数学基础预设 | 模拟套题(120min/周2) + 错题回顾(45min/周2) |
| 语文长效预设 | 实虚词背诵(30min/日) + 红楼梦精读(30min/日) |
| 体育健康预设 | 跑操有氧(30min/日) + 仰卧拉伸(15min/日) |

- 一键导入全部任务，已导入的模板置灰不可重复点击

### 3.3 任务 CRUD

**任务数据结构**：

```typescript
interface PlanTask {
  id: number;
  subject: string;          // 学科
  title: string;            // 任务描述
  frequency: string;        // 每日｜隔日｜周2次｜周3次｜周4次｜周5次｜选择性
  estimatedMin: number;     // 每次预计耗时
  priority: string;         // 紧急｜基础｜常规｜长效
  requirement: string|null; // 执行要求（锁图标提示）
  templateSource: string|null; // 来源预设模板名
}
```

**操作**：

| 操作 | 交互 |
|------|------|
| 新增 | 每学科表格底部「＋ 添加任务」→ 展开内联表单 → 填写 → 添加 |
| 编辑 | 点击 ✎ → 内联表单替换当前行 → 保存/取消 |
| 删除 | 点击 🗑 → confirm → 移除 |
| 保存计划 | 顶部按钮 → API PUT 整个 plan → 显示「已保存 ✓」 |
| 激活计划 | 顶部按钮 → API PUT 激活 → 按 frequency 生成每日任务 |

### 3.4 过滤标签

- `[全部]` + 各学科按钮
- 选中学科 → 只显示该学科的任务组
- 未选中的学科隐藏

### 3.5 统计概览

| 指标 | 计算方式 |
|------|----------|
| 任务总数 | `tasks.length` |
| 覆盖学科 | 去重 subject 数量 |
| 日均耗时 | Σ(estimatedMin × 频率系数)，频率系数：每日=1，隔日=0.5，周2次=2/7... |
| 阶段天数 | `end_date - start_date` 天数差 |

## 四、业务闭环数据流

```
PlanEditorPage               DashboardPage              ReviewSection
(制定计划)     ──保存/激活──→  (每日执行)   ──打卡──→    (复习整理)
     ↑                                                    │
     └────────── 迭代优化 ←────────────────────────────────┘
```

1. **制定**：在 PlanEditorPage 编辑阶段信息、导入预设、配置任务
2. **激活**：API 根据 frequency 生成 daily_tasks 记录
3. **执行**：DashboardPage 展示每日任务，用户打卡、记录
4. **反馈**：打卡面板的 score/gains/improvements 进入复习资料库
5. **迭代**：ReviewSection 的「加入次日计划」反馈到下一个周期的任务

## 五、API 对接清单

| 序号 | API 端点 | 方法 | 说明 | 优先级 |
|------|---------|------|------|--------|
| 1 | `/api/phases/:id` | GET | 获取阶段详情 + 任务列表 | P0 |
| 2 | `/api/phases/:id/plan` | PUT | 保存完整计划（phase + tasks[]） | P0 |
| 3 | `/api/phases/:id/activate` | PUT | 激活计划，按 frequency 生成 daily_tasks | P0 |
| 4 | `/api/phases/:id/tasks` | POST | 新增单个任务 | P1 |
| 5 | `/api/phases/:id/tasks/:taskId` | PUT | 更新单个任务 | P1 |
| 6 | `/api/phases/:id/tasks/:taskId` | DELETE | 删除单个任务 | P1 |
| 7 | `/api/presets` | GET | 获取可用预设模板列表 | P2 |
